### Engineering principles

> **Make it observable.** If an agent run cannot be inspected or replayed, debugging becomes guesswork.

> **Own the boring layer.** Queues, schemas, retries, authorization, and state transitions are where production systems earn their reliability.

> **Automate the second run.** Learn from the first execution. Turn the repeatable parts into software.

### 02 / Tracekit
**Replayable execution traces for coding agents**

A local-first tool for inspecting AI coding-agent sessions. Record tool calls, terminal commands, and file diffs, then replay the session in a local viewer.

Built around a simple idea: agent debugging should start with evidence, not another prompt.

- Inspect execution history
- Trace commands and tool calls
- Review file changes
- Replay recorded sessions locally

[**Source code ↗**](https://github.com/ANSHSINGH050404/Tracekit)
